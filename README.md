# 夜市游乐摊 · 套圈 & 打气球

国内夜市/庙会风格的 3D 小游戏：Three.js 渲染 + Rapier 刚体物理，所有模型、贴图、音效都是代码现场生成的，没有外部素材。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端里显示的地址即可。`npm run build` 生成可直接部署的 `dist/`。

## 玩法

**套圈**（10元15个）
- 移动鼠标瞄准；指到奖品上时，会有一个“幻影圈”悬在奖品顶上
- 按住左键稳住手：准星从晃动慢慢收紧，变成金色时最稳；按太久手会酸，又开始抖
- 松开出手；滚轮调整抛物线高低（平抛 / 高抛）
- 圈必须真正套住奖品（奖品整个在圈孔里）才算，压在奖品身上不算
- 越往后的奖品越值钱，也越难套

**打气球**（10元20枪）
- 鼠标瞄准，左键开枪；按住右键用机械瞄具（照门 + 准星），晃动小很多
- 和真摊位一样，枪的准星有点歪（每轮都不一样），先打几枪摸清偏向再修正
- 打在气球边缘可能会擦边弹开
- 18 个送大熊，13 个送公仔，8 个送挂件

Esc 离开摊位，回到广场。

## 代码结构

| 文件 | 内容 |
| --- | --- |
| `src/main.js` | 渲染器、后期（Bloom）、相机切换、UI |
| `src/environment.js` | 夜空、地砖、远景楼、摩天轮、灯笼串、小吃摊 |
| `src/props.js` | 帐篷、灯箱招牌、灯笼、串灯、塑料凳等道具，以及静态网格合并 |
| `src/prizes.js` | 套圈奖品建模（啤酒、青花瓷、招财猫、存钱罐、小熊……） |
| `src/ringToss.js` | 套圈：Rapier 物理（圈 = 18 段胶囊，奖品 = 凸包）、瞄准、判定 |
| `src/balloon.js` | 打气球：气枪模型、机瞄、气球墙、爆破碎片 |
| `src/audio.js` | WebAudio 合成音效与背景音乐 |
| `src/textures.js` | Canvas 程序化贴图 |
